# 🧠 Python for Us

> A hands-on computer vision playground focused on understanding how vision systems work from classical image processing to modern object detection.

This repository documents practical experiments in **Python, OpenCV, computer vision, and YOLO-based detection**.

## 🚀 Featured Project

### 🔥 Smoke & Fire Detection

A computer-vision application that combines classical image-processing ideas with a YOLOv8n model to detect potential fire and smoke in visual input.

**Focus areas**
- Image and video processing with OpenCV
- Color-space and segmentation techniques
- Computer-vision heuristics
- YOLOv8 object detection
- Real-time inference
- Python application structure
